# Confidentiality and GDPR choices

- The dataset is simulated: no real person is represented.
- Even so, the project follows the rules a real HR dataset needs: anonymous IDs, no names, age shown in bands, groups under 5 people hidden, aggregated views only, no employee-level export.
- The Excel lookup sheet exists to show XLOOKUP skills; in a real HR file it would be restricted to authorised users.
